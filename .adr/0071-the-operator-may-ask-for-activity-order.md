# 0071 — The operator may ask for activity order

- **Status:** Superseded by [ADR 0147](./0147-a-pane-list-keeps-its-place-and-the-footer-holds-views.md) (2026-11-16)
- **Decided:** The operator may ask a pane list to run by activity, and later by cache expiry. The choice is one value per device, place stays the default, and the clock is read once per opening, never on a poll (see ADR 0147).
