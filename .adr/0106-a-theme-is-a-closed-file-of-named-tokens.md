# 0106: a theme is a closed file of named tokens

- **Status:** Superseded by [ADR 0148](./0148-a-theme-names-words-never-drawings-and-the-device-choice-wins.md) (2026-11-16)
- **Decided:** A theme is one closed JSON file of named tokens: an unknown key is refused with its name, and the default theme applies nothing. Its amendments added the version 2 shape, the palette and the display face, and a pasted theme in place of an import by link (see ADR 0148).
