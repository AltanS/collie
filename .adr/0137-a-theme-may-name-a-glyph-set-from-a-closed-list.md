# 0137: A theme may name a glyph set, from a closed list, and every icon is named by its meaning

- **Status:** Superseded by [ADR 0148](./0148-a-theme-names-words-never-drawings-and-the-device-choice-wins.md) (2026-11-16)
- **Decided:** A theme may name a glyph set from a closed list and never carries a drawing, and every icon is named by what it means through one key table. A set other than lucide is a lazy chunk outside the precache (see ADR 0148).
