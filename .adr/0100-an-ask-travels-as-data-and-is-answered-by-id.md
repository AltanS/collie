# 0100: an ask travels as data and is answered by id

- **Status:** Superseded by [ADR 0146](./0146-a-durable-agent-is-a-session-with-no-screen-that-acts-by-id.md) (2026-11-16)
- **Decided:** An ask is data on the pane and is answered by its id, with a receipt written first, and only by a person's tap. The push guard caps pushes on disk and never what is shown, and a program should derive the ask id from the tool call; ADR 0104 added the session to the guard key, and ADR 0146 states the rule today.
