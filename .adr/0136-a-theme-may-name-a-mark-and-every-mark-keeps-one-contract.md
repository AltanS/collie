# 0136: A theme may name a mark, and every mark keeps one contract

- **Status:** Superseded by [ADR 0148](./0148-a-theme-names-words-never-drawings-and-the-device-choice-wins.md) (2026-11-16)
- **Decided:** A theme may name a header mark from a closed list, and every mark keeps one contract that a conformance suite holds. Its rule that only a theme names the mark was reversed by its own amendment: a device's own pick now wins (see ADR 0148).
