# 0104: a program is a session

- **Status:** Superseded by [ADR 0146](./0146-a-durable-agent-is-a-session-with-no-screen-that-acts-by-id.md) (2026-11-16)
- **Decided:** A durable program is a session of the Collie the person already runs, listed in `sources.json`, so the local case needs no second Collie and no crew. Each source is one more session with its own adapter, poller and disk folder; its exit was withdrawn on 2026-10-28, and ADR 0146 states the rule today.
